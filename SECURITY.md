# Security Policy

## Supported Versions

Only the latest version on the `main` branch is currently supported for security updates. 
Because `pi-casso` is an experimental meme project, there are no stable release series or LTS guarantees.

## Reporting a Vulnerability

If you discover a security vulnerability in `pi-casso`, please do NOT open a public issue. 
Instead, please contact the maintainer directly or use the GitHub Security Advisory feature to report it privately.

Given the nature of the project (no network listeners, local data only, no privileged execution), 
most bugs will be treated as standard issues rather than critical security vulnerabilities, 
but vulnerabilities leading to arbitrary code execution or significant resource exhaustion 
on unexpected inputs will be addressed.
